# Web Album Pro - Thư Viện Ảnh Google Drive Chuyên Nghiệp

Hệ thống quản lý và chia sẻ album ảnh Google Drive chuyên nghiệp dành cho Studio / Nhiếp ảnh gia & Khách hàng.

## ✨ Tính Năng Nổi Bật

1. **Phân Quyền Theo Tài Khoản**:
   - Chủ Studio đăng nhập tài khoản Google để tạo, chỉnh sửa, đổi ảnh bìa, xóa album.
   - Mỗi tài khoản có Dashboard riêng biệt quản lý trọn bộ album của mình.

2. **Mã Truy Cập Album Độc Nhất (Album Access Code)**:
   - Mỗi album tự động có một Mã truy cập riêng (ví dụ: `DD8899`, `KY12A1`).
   - Hỗ trợ tạo Link trực tiếp (`#album/MÃ_ALBUM`) và Mã QR 1-chạm để gửi khách hàng.

3. **Khách Xem & Chọn Ảnh Tự Do (Không Cần Đăng Nhập)**:
   - Khách chỉ cần mở link hoặc nhập mã album là vào xem ngay lập tức.
   - Hỗ trợ đầy đủ tương tác: Thả tim ❤️, Chọn ảnh ✓, Đặt kích thước in ảnh 🖨️, Ghi chú yêu cầu chỉnh sửa 📝.
   - Tải file ZIP trọn gói và xuất danh sách tên file sang Lightroom / PC Sorter.

4. **Đồng Bộ Cloud 2 Chiều Google Sheets**:
   - Tự động lưu trữ danh sách ảnh khách chọn, tim và ghi chú lên Google Sheets theo thời gian thực.

## 🚀 Hướng Dẫn Cài Đặt & Chạy Trực Tiếp

### Chạy Cục Bộ (Local):
Mở file `index.html` bằng bất kỳ trình duyệt web nào (hoặc sử dụng VS Code Live Server / `npx serve`).

### Triển khai lên Vercel:
1. Kết nối repository GitHub này vào [Vercel Dashboard](https://vercel.com).
2. Chọn **Other / Static HTML** và nhấn **Deploy**.
